使用 Calibre 管理 Kindle 电子书

2026年10月1日 · 阅读需 6 分钟
cbtpro
Front End Engineer

Calibre 是一款免费开源的电子书管理工具，支持电子书的格式转换、元数据编辑、书库管理以及向 Kindle 等阅读器设备传输书籍。本文以 macOS 为例，介绍从安装 Calibre 到把电子书传输到 Kindle 的完整流程。

安装 Calibre​

打开 Calibre 官网下载页面，点击 Download calibre 下载 macOS 版本的安装包。

等待浏览器下载完成，也可以使用其他下载工具下载。

在下载目录中找到 calibre-x.x.x.dmg 文件，双击打开，将 calibre 拖入 Applications 文件夹完成安装。

如果之前已经安装过 calibre，会提示是否替换，选择替换即可。升级版本时同样选择替换。

安装完成后打开 calibre，进入主界面。首次连接 Kindle 传书时，calibre 可能会提示 Amazon 破坏了 USB 传输书籍的封面显示，可以按照提示的 workaround 处理。

设置语言​

calibre 默认跟随系统语言，如果需要手动切换界面语言，点击屏幕左上角菜单栏的 calibre，选择 Preferences... 进入设置界面。

设置界面按功能分组：介面、格式轉換、匯入/匯出、分享、進階等。点击介面外觀进入外观设置。

在主要介面中找到選擇語言选项。

在下拉列表中选择需要的语言，例如中文、English 等。

有修改时应用按钮会高亮，点击保存修改。部分修改需要重启 calibre 后才会生效，比如修改界面语言。

如果不想保存修改，点击取消按钮返回上一步。

添加电子书到书库​

电子书文件可以从图灵社区等图书网站购买或下载，常见格式有 EPUB、MOBI、AZW3、PDF 等。

点击左上角的加入書本，在弹出的文件选择框中选择要添加的电子书，也可以直接把电子书文件拖拽到 calibre 的软件界面上。

添加成功后，电子书会出现在书库列表中，右侧可以看到封面、作者、格式等元数据信息。

传输电子书到 Kindle​

使用 USB 数据线将 Kindle 和电脑连接。

macOS 会弹出配件连接确认框，点击允许，允许 Amazon Kindle 连接到这台 Mac。

连接成功后，Kindle 屏幕会显示进入 USB 驱动器模式。在此模式下 Kindle 不能阅读，如果希望边充电边阅读，需要在电脑上弹出 Kindle 设备。

此时电脑可以像访问 U 盘一样访问 Kindle 的磁盘，电子书文件存放在 documents 目录中。

calibre 识别到 Kindle 后，在书库中选中要传输的书，点击工具栏的傳送至裝置。如果书籍的格式不被 Kindle 支持（例如 EPUB），calibre 会提示是否在上传到装置前自动转换格式，选择是即可。

传输过程中可以观察底部状态栏，会实时显示同步任务的状态，下图中工作数为 0，表示同步已完成，书籍左侧出现主記憶體标记说明设备上已存在该书。

同步完成后，Kindle 的书架上就能看到新传输的书籍了。

查看设备上的书籍​

calibre 工具栏的書庫和裝置按钮用于在本地书库和设备书籍之间切换视图。

点击裝置按钮切换到设备视图，可以看到电子书已经同步到 Kindle 中，右侧面板还会显示书籍在设备上的存储路径。

安全断开连接​

同步完成后，先在访达侧边栏点击 Kindle 设备右侧的推出按钮弹出设备，再拔掉数据线，避免损坏设备中的文件。

插件管理​

calibre 支持通过插件扩展功能。在设置界面的進階分组中点击插件，可以进行插件的安装与管理，支持两种方式：

  • 从 calibre 官方插件索引在线安装；
  • 从本地磁盘加载插件文件，离线安装包安装。

小结​

Calibre 覆盖了电子书管理的完整链路：从获取电子书、加入书库、编辑元数据，到格式转换、传输到 Kindle。配合插件系统，还可以进一步扩展去重、翻译、新闻抓取等能力，是 Kindle 用户管理电子书的得力工具。
